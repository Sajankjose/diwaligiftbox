# Geojit Diwali Wealth Box — prototype

An interactive Diwali investment-idea gift-box experience.

## Preview
Open `index.html` in a browser. No build system or dependencies required.

## Implemented
- Festive invitation, themed discovery and stock search
- Click-to-add and desktop HTML drag-and-drop
- Six initial stock compartments, expandable by three
- Multiple whole-share quantities for each stock
- Indicative value calculations and local draft persistence
- Contextual concentration and theme guidance
- Review panel and festive downloadable PNG card
- Optional stock names on gift image; quantities and investment amounts excluded

## Important caveats
- **Demo only**: stock reference prices are hardcoded illustrative values, not current market data.
- Rationale copy is indicative editorial text and requires Geojit Research/Compliance approval.
- There is no order placement, lead submission or broker integration.
- Logo and festive visuals need final approved branded assets before launch.
- The app has not been fully tested across all browsers/devices.

## Security and compliance
Before any public deployment: verify research dates, exchange identifiers, price feeds, disclosures, suitability messaging, consent, and brand assets. Do not imply that a manually created basket is a personalised recommendation or an executed trade.
